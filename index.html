GIT

es un sistema de control de versiones distribuido, gratuito y de código abierto. En palabras sencillas, es un programa que registra todos los cambios realizados en el código de un proyecto a lo largo del tiempo, permitiendo recuperar versiones anteriores y facilitando el trabajo colaborativo sin riesgo de pérdida de datos

Principales usos y beneficios:

  • Historial y reversión: Guarda un registro exacto de cada modificación. Si cometes un error, puedes "retroceder" el tiempo y restaurar una versión anterior que funcionaba correctamente.
  • Trabajo en equipo: Múltiples personas pueden trabajar en el mismo proyecto simultáneamente sin pisarse los cambios. Git se encarga de fusionar las modificaciones de todos de manera ordenada.
  • Ramas (Branches): Permite crear copias aisladas del proyecto (ramas) para desarrollar nuevas funciones o probar ideas sin alterar la versión principal.
  • Copias de seguridad: Al ser distribuido, cada desarrollador tiene una copia completa del proyecto y de su historial en su propia computadora.

GIT HUB

GitHub es una plataforma en la nube utilizada para almacenar, compartir y trabajar en equipo en proyectos de software. Funciona como una especie de "red social para desarrolladores", donde millones de personas y empresas colaboran en proyectos de código abierto y privados

¿Para que sirve?

  • Control de versiones: Permite guardar el historial de un proyecto y volver a cualquier versión anterior si algo sale mal (como una máquina del tiempo).
  • Trabajo en equipo: Facilita que múltiples personas modifiquen el mismo código al mismo tiempo sin sobrescribir el trabajo de los demás.
  • Respaldo seguro: Mantiene copias de seguridad de todo el código en la nube.
  • Portafolio profesional: Funciona como una red social para desarrolladores. Los programadores comparten su trabajo público y las empresas lo revisan como parte de sus procesos de contratación.
  • Proyectos de código abierto: Millones de proyectos públicos permiten a cualquier usuario descargar aplicaciones o contribuir con mejoras.
